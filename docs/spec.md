# React 노트 앱 통합 스펙

## 1. 공식 확인 요구사항

- React를 이용하여 노트 앱을 제작합니다.
- Redux와 같은 상태관리 라이브러리를 사용합니다.
- TypeScript를 사용합니다.
- 결과물이 올라간 저장소 주소를 제출합니다.
- 제공된 결과 예시를 참고합니다.

> 공식 결과 예시와 이 문서가 충돌하면 공식 과제 안내와 결과 예시를 우선합니다.

## 2. 권장 최소 기능

다음 기능은 운영 가능한 노트 앱을 위한 권장 최소 기준입니다.
강사가 별도 필수 범위를 제시한 경우 해당 기준을 우선합니다.

- 노트 목록
- 노트 작성
- 노트 선택과 내용 확인
- 노트 수정
- 노트 삭제
- 노트가 없을 때 빈 상태
- 빈 제목 또는 공백 제목 저장 차단

## 3. 권장 데이터 구조

```ts
export interface Note {
  id: string
  title: string
  content: string
  createdAt: string
  updatedAt: string
}
```

프로젝트에서 사용하지 않는 필드는 추가하지 않습니다.

## 4. 상태관리 기준

### 전역 상태

- 전체 노트 목록
- 현재 선택된 노트 ID

### 로컬 상태

- 작성·수정 중인 입력값
- 특정 컴포넌트에서만 사용하는 UI 상태

같은 노트 데이터를 전역 상태와 로컬 상태에 중복 저장하지 않습니다.

## 5. 수용 기준

### 기술

- [ ] 주요 React 파일이 `.tsx`로 작성되었습니다.
- [ ] `Note` 타입이 정의되어 있습니다.
- [ ] Redux Toolkit 또는 동등한 상태관리 라이브러리를 실제로 사용합니다.
- [ ] 노트 목록의 기준 데이터가 store에서 관리됩니다.
- [ ] `npm run build`가 성공합니다.
- [ ] 불필요한 `any`와 `@ts-ignore`가 없습니다.

### 기능

- [ ] 노트가 없을 때 빈 상태가 표시됩니다.
- [ ] 정상 입력으로 노트를 만들 수 있습니다.
- [ ] 빈 제목과 공백 제목은 저장되지 않습니다.
- [ ] 노트를 선택하여 내용을 확인할 수 있습니다.
- [ ] 선택한 노트만 수정할 수 있습니다.
- [ ] 선택한 노트만 삭제할 수 있습니다.
- [ ] 선택된 노트를 삭제하면 선택 상태가 정리됩니다.
- [ ] 다른 노트 데이터가 의도치 않게 변경되지 않습니다.

## 6. 기본 제외 범위

- 회원가입·로그인
- 외부 데이터베이스와 서버 API
- 실제 사용자 데이터
- 외부 AI API
- 자동 배포
- MCP·Skills·Hooks·Subagents·다중 에이전트
- 복잡한 디자인 시스템

- LocalStorage
- 검색·정렬
- 태그·중요 노트
- Markdown 미리보기
- 자동 저장
- 테스트 코드
- 접근성 개선
