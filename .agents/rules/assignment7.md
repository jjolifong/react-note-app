# Assignment 7 Workspace Rule

다음 문서를 프로젝트 기준으로 사용한다.

- `AGENT_GUIDE.md`
- `docs/spec.md`
- `docs/plan.md`

최초 구현과 구조 변경은 Planning Mode에서 계획을 먼저 제안한다.

다음 작업은 사람의 승인을 받는다.

- 패키지·설정 변경
- 파일 삭제
- 프로젝트 전체 재작성
- Git push·배포
- 외부 API·DB·MCP 연결

구현 후 다음을 보고한다.

- 실제 변경 파일
- 스펙 충족 여부
- build 결과
- 핵심 기능 테스트 결과
- 남은 문제

특강 7에서는 Skills, Workflows, Hooks, MCP, Subagents와 다중 에이전트를 추가하지 않는다.
